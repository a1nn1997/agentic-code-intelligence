## Phase 2 — Final Report

Stopped at Phase 2's <stop>. Phase 3 (sandbox) not started. 73 tests pass (+18), ruff clean, mypy --strict clean, built against ./.venv.

1. Retrieval primitive signatures — RetrievalServiceImpl(db, workspace_root, user_id, *, scope, budget_tokens):
   search_symbols(snap, query, limit=20)->list[Symbol]; definition(snap, name)->Symbol|None;
   references(snap, name)->list[SpanRef]; read_span(snap, span)->RetrievalResult (primary/cheapest);
   read_file(snap, path)->RetrievalResult (possible, costlier); list_dir(snap, path)->RetrievalResult;
   structural_grep(snap, pattern, limit=50)->list[SpanRef]. RetrievalResult = content (post-redaction) + byte_count + token_cost. Every query pinned to SnapshotRef(workspace_id, commit); drifted head refused.

2. Token-accounting formula — token_cost = PER_CALL_OVERHEAD(1) + ceil(byte_count(returned_content)/BYTES_PER_TOKEN(4)) on post-redaction bytes. Identical constants across primitives => cost differs only by returned bytes => span < file provably. Metadata primitives meter the canonical sorted text of returned symbols/spans.

3. Ledger reserve/commit — one choke point _charge(tokens), one write txn: (1) pre-op check, if tokens > remaining (ceiling - committed - net_reserved) raise BudgetExceeded BEFORE any ledger write (refused call: row count AND balance unchanged); (2) RESERVE -> (3) COMMIT (what spent_tokens counts) -> (4) RELEASE (net reserved back to 0). After a served call, committed spend rose by exactly the cost, reserved is 0.

4. Secret redaction — redaction.py, applied inside _meter_content on every content-returning primitive, before content leaves the module. Patterns: provider keys (sk_live_/sk_test_/sk-live-), JWT tokens, name-based secret/password/token/api_key/signing_key assignments; DATABASE_URL allow-listed. Only the VALUE -> «redacted:reason» (structure preserved, idempotent). Logged as retrieval.secret_redacted with reason+count, never the value; noted on the ledger entry. Tested against all 5 Phase-1 planted secrets.

5. Determinism across replay — result is a pure function of (immutable snapshot, query), snapshot pinned via SnapshotRef and index loaded once per (workspace, commit); cost is a pure function of returned post-redaction bytes; redaction idempotent. => same query on same snapshot -> byte-identical content AND identical accounting -> Phase 4 replays with no double-charge/divergence.

Phase-1 debts carried into DESIGN.md §2 + ADR-0001: (a) name+language-scoped resolution (two same-named same-language symbols collapse into one reference set; sample repo unaffected, targets unique); (b) index-as-single-JSON scaling seam (fix: per-file partition store + prebuilt maps behind the unchanged Index/RetrievalService interfaces).
